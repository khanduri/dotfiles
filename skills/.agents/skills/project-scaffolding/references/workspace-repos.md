# Workspace repos

Bundled format example. At kickoff, a read-only scan of the user's workspace root
regenerates this file in the work item with the repos relevant to it, one line
of purpose each, taken from the README or manifest.

| Repo | Purpose |
|------|---------|
| `example-api` | Example HTTP service that serves widget data |
| `example-web` | Example browser front end for the widget catalog |
| `example-infra` | Example deployment and environment configuration |
